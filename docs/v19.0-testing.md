# Matomo 19.0 testing

## Scope and source decision

The appliance installs Matomo and its PHP dependencies from Debian 13
Trixie's signed package repository. MariaDB, Apache, Postfix, Adminer and
Webmin also come from the signed Debian Trixie and TurnKey repositories.

## Acceptance command

```sh
/sandboxed-git/turnkey/tools/test-v19-appliance matomo \
    --source /home/agent/.local/worktrees/turnkey-apps/matomo/fix-matomo-v19-report-visibility
```

## Supervised Matomo updates

Back up the appliance and database before updating. Refresh the signed package
metadata and run `apt-get install matomo`. Review the Debian package changelog
and Matomo upgrade notes before applying a major release transition.

## Economical preflight evidence

A disposable Debian Trixie package inspection confirmed that Matomo
`5.3.1+dfsg-1` and its runtime dependencies resolve from the signed stable
repository. The exact appliance command covers installation, firstboot,
authentication, analytics collection, archiving and reporting.

## Known limitation

The disposable container does not exercise appliance boot or firstboot service
ordering. The exact appliance acceptance command covers those paths. The Core
19 baseline supplies inherited ISO, bootloader and hardware-boundary evidence.
